SİVİL SAVUNMA S10 FE v5.0 — SIFIRDAN ANDROID PROJESİ

Bu proje önceki bozuk Android/WebView paketinin devamı değildir.
Kaynak olarak bu paketin içindeki:
  source/SivilSavunmaSinavPython.rar
dosyası kullanılır.

GitHub Actions derleme sırasında:
1) RAR'ı açar.
2) PC uygulamasının resources klasöründeki JSON'ları okur.
3) Android için tek ve temiz soru verisi üretir.
4) JavaScript sözdizimini kontrol eder.
5) APK'yı derler.
6) APK içinde app.js ve data.js bulunduğunu doğrular.
7) Artifact olarak APK'yı verir.

GITHUB:
Repo köküne BU ZIP'İN İÇİNDEKİ TÜM DOSYA/KLASÖRLERİ yükle.
Eski app.ss reposunu kullanacaksan en temiz yöntem eski dosyaları silip bu paketi tek başına yüklemektir.

Actions > Build S10 FE APK > Run workflow
